# DeepSeek Harness Desktop v1.3.1

Harness Lab now turns raw trajectory differences into concise Chinese diagnostic conclusions.

## New in this release

- Adds a prominent local-rule diagnosis panel above comparison metrics.
- Identifies which run has the cleaner, more stable execution trajectory.
- Summarizes material differences in tool calls, steps, retries, failures, and duration.
- Produces targeted recommendations for repeated tool loops, failed commands, unrecovered failures, file churn, and late testing.
- Clearly states that trajectory efficiency does not replace human review of final business quality.
- All diagnosis remains deterministic and local; no prompt or session content is sent to a model or remote service.
